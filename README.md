# ChargerFlash

Мини-приложение для iPhone: при подключении зарядки проигрывает звук и на мгновение показывает фото.

Схема работы: **Shortcuts-автоматизация «Зарядное устройство» → открывает ChargerFlash → приложение сразу играет звук и мигает фото.**

---

## Что важно понимать про iOS

1. Приложение **не может** само «висеть в фоне и ловить зарядку». Триггер даёт системная автоматизация Shortcuts — она работает, даже если приложение закрыто или телефон заблокирован.
2. Действие «Открыть приложение» в автоматизации **требует разблокированного телефона**. Если экран заблокирован, iOS не откроет приложение, и вспышки не будет. Это ограничение системы, обойти нельзя.
3. Задержка от «воткнул кабель» до звука — примерно **1–2 секунды** (система запускает автоматизацию, потом приложение).
4. «На миллисекунду» технически не имеет смысла: меньше ~50 мс глаз не замечает. По умолчанию фото висит **250 мс** — это и читается как вспышка. Меняется одной константой.
5. После вспышки приложение остаётся открытым (чёрный экран). Автоматически свернуть его iOS не даёт — есть только приватный трюк, см. комментарий в конце `Sources/ChargerFlashApp.swift`.

## 1. Свои фото и звук

Просто замени файлы (имена менять не нужно):

| Что | Файл |
|---|---|
| Фото | `Resources/flash-photo.jpg` (подойдёт `.png`, `.heic`, `.jpeg`) |
| Звук | `Resources/flash-sound.mp3` (подойдёт `.m4a`, `.wav`, `.caf`, `.aiff`) |

Звук уже твой — 1,27 с, моно, 48 кГц. Фото тоже на месте (960×1280, вертикальное).

Если хочется, чтобы фото висело всю длину звука, а не 250 мс — поставь `holdMilliseconds = 1270` в `FlashController.swift`.

Звук играет через аудиосессию `.playback`, поэтому **слышен даже при включённом бесшумном режиме**.

## 2. Сборка

Проект генерируется через [XcodeGen](https://github.com/yonaskolb/XcodeGen) из `project.yml` — так не нужно тащить в репозиторий `*.xcodeproj`.

### Вариант A. Есть Mac

```bash
brew install xcodegen
xcodegen generate
open ChargerFlash.xcodeproj
```

В Xcode: таргет **ChargerFlash** → *Signing & Capabilities* → выбрать свою Team → подключить iPhone → **Run**.

### Вариант B. Только Windows (Mac не нужен)

1. Залей папку в репозиторий на GitHub.
2. Вкладка **Actions** → workflow **Build unsigned IPA** → *Run workflow*.
3. Скачай артефакт `ChargerFlash-ipa` (внутри `ChargerFlash.ipa`).
4. Установи на iPhone через [Sideloadly](https://sideloadly.io) (Windows) со своим Apple ID:
   - **бесплатный Apple ID** — подпись живёт 7 дней, потом переустановить;
   - **платный аккаунт разработчика ($99/год)** — подпись на год; можно поставить SideStore/AltStore и обновлять автоматически.
5. На iPhone: *Настройки → Основные → VPN и управление устройством* → доверять профилю.
   На iOS 16+ ещё: *Настройки → Конфиденциальность и безопасность → Режим разработчика* → включить → перезагрузить.

> Bundle ID по умолчанию `com.example.chargerflash`. Лучше заменить на свой (`project.yml` → `PRODUCT_BUNDLE_IDENTIFIER`), чтобы не пересекаться с другими приложениями.

## 3. Автоматизация в Shortcuts (это и есть «триггер зарядки»)

1. Приложение **Shortcuts** (Команды) → вкладка **Автоматизация** → **+**.
2. Триггер **«Зарядное устройство»** (Charger) → **«При подключении»**.
3. Поставь **«Сразу выполнять»** (Run Immediately). Галочку «Спрашивать до запуска» выключи, «Уведомлять при запуске» — тоже.
4. Действие → **«Открыть приложение»** (Open App) → **ChargerFlash**.
5. Готово. Воткни кабель для проверки.

Если телефон разблокирован и приложение не на переднем плане — вспышка сработает. Если телефон заблокирован, iOS не откроет приложение (см. пункт 2 выше).

## 4. Настройки поведения

Всё в `Sources/FlashController.swift`, блок «Настройки»:

```swift
static let holdMilliseconds = 250   // сколько фото на экране
static let fadeMilliseconds = 120   // плавное исчезновение, 0 — мгновенно
static let volume: Float = 1.0      // громкость
static let duckOtherAudio = false   // true — приглушать музыку вместо паузы
static let debounce: TimeInterval = 0.5
```

Кадрирование фото — `Sources/FlashView.swift`, константа `fillScreen`:

- `true` — фото заполняет весь экран, лишнее обрезается;
- `false` — фото целиком, а поля закрывает размытая копия (лучше для вертикальных фото 3:4 и селфи, которые иначе теряют бока).

При `fillScreen = true` рядом есть `horizontalBias` (0 — центр, 0.5 — край): сдвигает кадр, если главное на фото не по центру. Сейчас стоит 0.25, потому что человек на снимке левее центра.

## 6. Проверка и типовые проблемы

| Симптом | Причина / решение |
|---|---|
| Тапнул по экрану — вспышка повторилась | Так и задумано, это тест-режим без передёргивания кабеля. |
| Автоматизация молчит | «Спрашивать до запуска» включено; или телефон заблокирован; или автоматизация выключена в списке. |
| Звука нет | Файл не попал в бандл (проверь имя `flash-sound.*`), или громкость мультимедиа на нуле. |
| Фото обрезано | `.scaledToFill()` → `.scaledToFit()` в `FlashView.swift`. |
| Sideloadly ругается на IPA | Сборка упала — смотри лог workflow; `.ipa` должен содержать папку `Payload/ChargerFlash.app`. |
| Через 7 дней приложение не запускается | Истекла бесплатная подпись — переустановить через Sideloadly (или платный аккаунт). |
