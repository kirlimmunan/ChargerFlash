## Продолжить завтра

```powershell
# 1. iTunes с сайта Apple (не из Microsoft Store). Появится UAC — нажать «Да».
winget install --id Apple.iTunes -e --accept-package-agreements --accept-source-agreements

# 2. Запустить Sideloadly
& "$env:LOCALAPPDATA\Sideloadly\Sideloadly.exe"
```

Дальше по шагам:

1. iPhone кабелем → на телефоне «Доверять».
2. iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → вкл → перезагрузка.
3. Sideloadly: перетащить `dist\ChargerFlash.ipa`, ввести Apple ID (бесплатный), Start.
4. iPhone: Настройки → Основные → VPN и управление устройством → доверить профиль.
5. Shortcuts → Автоматизация → + → «Зарядное устройство» → «При подключении» → «Сразу выполнять» (без «Спрашивать до запуска») → действие «Открыть приложение» → ChargerFlash.

## Помнить

- Бесплатная подпись живёт **7 дней**, потом переустановить через Sideloadly.
- Вспышка срабатывает только при **разблокированном** телефоне (ограничение iOS на действие «Открыть приложение»).
- Задержка от кабеля до звука ~1–2 с.
- Фото на экране 250 мс (`holdMilliseconds` в `FlashController.swift`), звук играет свои 1,27 с.
- Тап по экрану в приложении = повтор вспышки (для теста).

## Если захочется поменять

- Другое фото → заменить `Resources\flash-photo.jpg`.
- Другой звук → заменить `Resources\flash-sound.mp3`.
- Другая длительность/громкость → константы в `Sources\FlashController.swift`.
- Кадрирование фото → `fillScreen` и `horizontalBias` в `Sources\FlashView.swift`.
- После правок: `git add -A`, `git commit -m "..."`, `git push` → Actions пересоберёт `.ipa`.
